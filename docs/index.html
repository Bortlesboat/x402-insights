What judges can inspect

The demo is not another chat interface. It is operational evidence for teams asking what an autonomous workflow touched, spent, retried, blocked, and finished.

success

Vendor risk review

Records search, human approval, x402 enrichment payment, and final cleared outcome.

retry

Supplier onboarding

blocked

High-risk payment

Approval request, rejection, blocked paid action, final error state, and exportable JSON.

Small SDK surface

AgentOps Ledger works around existing agent runtimes. Wrap the workflow, emit events, and keep the agent stack you already use. 

const run_id = await startRun({
  agent,
  workflow
});

await trackToolCall({
  run_id,
  step_name,
  tool_name,
  fn
});

await trackApproval({
  run_id,
  approval_status
});

await trackPayment({
  run_id,
  endpoint,
  cost,
  currency
});

await finishRun({
  run_id,
  status,
  summary
});
